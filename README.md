# TCRankingViewer

FFXIV 繁中服（TC）Dalamud 插件，自動查詢隊友的零式 / 絕本排名，顯示於插件視窗與聊天框。

---

## 安裝

1. 在 Dalamud 設定 → 自訂插件庫，加入以下 URL：
   ```
   https://raw.githubusercontent.com/SamoyedQQ/TCRankingViewer/main/repo.json
   ```
2. 在插件安裝器搜尋 **TCRankingViewer** 並安裝。
3. 安裝完成後，前往 `/tcrank config` 輸入許可證金鑰，插件才能下載排名資料。

---

## 功能概覽

| 功能 | 說明 |
|------|------|
| 隊伍排名視窗 | 顯示當前隊伍成員的零式 / 絕本排名 |
| 招募面板側邊欄 | 點開招募詳情時，自動於右側顯示各隊員排名 |
| 聊天通知 | 隊友加入時在聊天框顯示排名摘要 |
| 清關 Badge | 最高難度清關標記（歐米茄✓、龍詩✓、M4S✓ 等） |
| 黑名單 | 標記特定玩家並以紅色顯示 |

## 隊伍排名視窗（`/tcrank`）

進入隊伍後輸入 `/tcrank` 開啟。

### 欄位說明

| 欄位 | 說明 |
|------|------|
| 玩家名稱 | 角色名稱；★ 代表自己；有清關 Badge 時顯示於名稱右方 |
| 職業 | 該排名條目的職業 |
| 副本 | 排名所屬的副本名稱 |
| 排名 | 職業內排名（金色 = 前 3、白色 = 前 10、銅色 = 前 50） |
| rDPS | Raid DPS |
| aDPS | Adjusted DPS |

### 標籤頁篩選

視窗頂部有四個標籤頁，可篩選要顯示的副本類型：

- **全部**：顯示所有副本的最佳成績
- **零式**：僅顯示零式副本（M1S–M4S）
- **絕境戰**：僅顯示絕本（歐米茄、龍詩、巴哈姆特等）
- **極 / 幻**：僅顯示極神與幻神副本

### 展開 / 收合多筆成績

若某位玩家在多個副本有排名，名稱左側會出現 ▶ 箭頭；點擊可展開，查看所有副本的詳細成績。

展開時成績依**職業分組**顯示：同一職業的所有副本排名集中在一起，不同職業再接續。

在「**全部**」標籤頁展開時，成績會依照類別分段（絕境戰 → 零式 → 極/幻 → 過版本），各類別內再依職業分組。

### 清關 Badge

名稱右側可能顯示清關 Badge，代表該玩家在對應難度有過 DPS 排名紀錄。優先順序（高 → 低）：

`伊甸✓` `歐米茄✓` `龍詩✓` `巴哈✓` `絕亞✓` `神兵✓` `M4S✓` `M3S✓` `M2S✓` `M1S✓` `極女王✓` `幻白虎✓`

### 工具列按鈕

- **重新整理隊伍**：手動重新讀取目前隊伍成員排名
- **重新下載資料**：強制重新從伺服器下載排名資料
- **重整黑名單**：重新讀取黑名單檔案
- **設定**：開啟設定視窗

## 招募面板排名視窗

點開任意招募詳情（招募介面左鍵點選招募條目）時，插件自動在 **LookingForGroupDetail 視窗的右側** 顯示一個側邊欄。

### 欄位說明

| 欄位 | 說明 |
|------|------|
| 玩家 | 角色名稱；有 Badge 時顯示於名稱右方 |
| 現職 | 招募時該槽位使用的職業 |
| 職業 | 排名條目的職業（可能與現職不同） |
| 副本 | 排名所屬副本 |
| 排名 | 職業內排名 |
| rDPS / aDPS | Raid DPS / Adjusted DPS |

### 自動切換標籤頁

插件會根據招募的副本類型，自動切換到對應標籤頁（零式 / 絕境戰 / 極 / 幻）。

### 無法解析的成員

部分跨伺服器或未在招募清單中出現過的玩家，插件會嘗試透過 CharaCard 自動解析名稱；若仍無法取得，該行顯示「**（無法解析）**」。

> **ID 快取機制**：只要曾與某位玩家**同隊**過一次，插件就會將其 ContentId → 名稱的對應關係儲存至本機快取。此後在招募面板或隊伍中再次遇到同一位玩家時，即使對方無法觸發 CharaCard，也能直接從快取解析名稱並顯示排名，**不再顯示「無法解析」**。

### 刷新按鈕

視窗右上角有**刷新**按鈕，可手動重新讀取目前招募詳情的成員資料。

## 設定（`/tcrank config`）

### 許可證金鑰

使用本插件需要有效的許可證金鑰。輸入金鑰後點**儲存**；金鑰以 Windows DPAPI 加密儲存於本機，綁定至當前使用者帳號，不以明文保存。

### 通知

| 選項 | 說明 |
|------|------|
| 隊友加入時，在聊天框顯示排名通知 | 有隊友進入隊伍時，自動在聊天框列出其排名摘要 |
| 隊友加入時，自動開啟排名視窗 | 有隊友進入時，自動顯示主視窗 |
| 未上榜的隊友也顯示通知 | 勾選後，即使隊友無排名紀錄也會發出通知 |

### 資料快取

- **自動更新間隔**：排名資料的本機快取有效時間（60–1440 分鐘）。在有效時間內不會重複下載，超過後自動重新取得。

### 黑名單

黑名單儲存於本機的純文字檔案（`.txt`）；按**開啟**用文字編輯器編輯：

```
# 每行填入一個玩家名稱，儲存後自動生效
# 以 # 開頭的行為註解
# 可加備註：玩家名稱 # 備註文字
草莓小蛋糕
某某某 # 喜歡搶奶
```

被列入黑名單的玩家在視窗中以**紅色**顯示，並在名稱右方標示「**黑名單Ｘ**」，點擊可查看備註。

> **遊戲黑名單匯入**：插件會在登入後自動讀取遊戲內黑名單（含遊戲端填寫的備註）並合併到本機檔案。本機已有的條目永遠優先，不會被覆蓋；本機若有名字但無備註、遊戲端有備註，會自動補上。

### 社群資料同步

TCRankingViewer 提供**選擇性**的社群同步功能，讓所有授權使用者的本機資料得以互相補充。  
四項開關均可在設定視窗中獨立啟用或關閉，預設全部開啟。

| 設定 | 說明 |
|------|------|
| 上傳本機 CID 快取 | 將本機收集的 ContentId → 角色名稱對應貢獻至共享快取 |
| 下載社群 CID 快取 | 啟動時下載其他使用者貢獻的 CID 快取，補充本機未有的對應 |
| 上傳本機黑名單 | 將本機黑名單（含備註）貢獻至共享黑名單 |
| 下載社群黑名單 | 啟動時下載共享黑名單，與本機黑名單合併判斷 |

**合併策略**：本機資料優先；伺服器資料不覆蓋本機已有的條目。  
**隱私說明**：CID 快取僅包含遊戲內公開可見的 ContentId → 角色名稱對應；共享黑名單僅包含玩家名稱與備註，不含任何個人識別資訊。若不希望分享資料，關閉對應上傳開關即可。

## 資料來源

排名資料由後端服務每小時自動爬取並快取，插件僅從該服務讀取：

| 類型 | 原始來源 |
|------|------|
| 零式 / 極神 | [ranking.init.engineer](https://ranking.init.engineer)（Kantai235） |
| 絕本 | [samoyedqq.github.io/TCtomestone](https://samoyedqq.github.io/TCtomestone)（SamoyedQQ） |

排名為**同職業內的 rDPS 排名**，每次啟動或快取過期時自動更新，無需手動操作。

---

## 注意事項

- 使用插件前須先在設定頁面輸入有效的**許可證金鑰**，否則無法下載排名資料。
- 排名資料僅包含**有在 TC 繁中服資料庫登錄過**的玩家，未上榜顯示「未上榜」。
- 招募面板的「現職」欄位顯示招募時該玩家填寫的職業；「職業」欄位顯示排名資料庫中的職業（兩者可能不同）。
- 招募面板的玩家名稱解析需要對方曾在招募清單中出現，或觸發 CharaCard 查詢。部分情況下可能顯示「無法解析」；但**只要曾與對方同隊一次**，其 ID 即永久存入本機快取，往後遇到時皆可正常解析。
- 本插件為唯讀操作，不會修改遊戲資料或對伺服器造成任何影響。

## 技術棧 & 建置說明

> 協作開發者請另見 [CONTRIBUTING.md](CONTRIBUTING.md)，內含完整架構說明與發版流程。

### 技術棧

| 層次 | 技術 |
|------|------|
| 語言 / 執行環境 | C# 12 / .NET 9 |
| 插件框架 | [Dalamud.NET.Sdk 14.0.1](https://www.nuget.org/packages/Dalamud.NET.Sdk) |
| UI 渲染 | ImGui.NET（透過 Dalamud 提供，`Private=false`） |
| 遊戲結構存取 | FFXIVClientStructs（AgentLookingForGroup、AtkUnitBase 等） |
| HTTP | `System.Net.Http.HttpClient`（內建） |
| JSON | `System.Text.Json`（內建） |
| 金鑰儲存 | Windows DPAPI（`System.Security.Cryptography.ProtectedData`） |

### 建置步驟

**需求**：.NET 9 SDK、FFXIV TC 繁中服 + XIVLauncher（含 Dalamud）

```powershell
# 還原依賴
dotnet restore

# 建置
dotnet build -c Release

# 輸出位置：bin\Release\TCRankingViewer.dll
```

建置完成後，將 `bin\Release\TCRankingViewer.dll` 複製至 Dalamud 的 Dev Plugin 目錄即可載入測試。

### 主要模組

| 檔案 | 職責 |
|------|------|
| `Plugin.cs` | 入口點，靜態持有所有服務 |
| `RankingService.cs` | 帶 HMAC 認證向後端取得排名資料，建立玩家名稱索引 |
| `PartyFinderInspector.cs` | 偵測招募面板、收集隊員資訊、觸發 CharaCard 查詢 |
| `CharaCardLookup.cs` | AgentCharaCard hook，解析跨服玩家名稱 |
| `PartyWatcher.cs` | 監控隊伍成員變化，觸發查詢與聊天通知 |
| `Configuration.cs` | 插件設定，含 DPAPI 加密許可證金鑰 |
| `RankingModels.cs` | 資料模型、副本元資料、職業名稱對照 |
| `MainWindow.cs` | 主視窗（`/tcrank`） |
| `PartyFinderWindow.cs` | 招募面板側邊視窗 |
